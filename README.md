# EduVault

Secure workspace for **academic documents** — organize and find class and administrative files by institution, year, class, subject, and term. Built by **PersonAI**.

**Full project description (vision, core concepts, architecture, dev & deploy):** [docs/PROJECT.md](./docs/PROJECT.md)

**Cloudflare Pages + D1 deployment:** [CLOUDFLARE_D1_SETUP.md](./CLOUDFLARE_D1_SETUP.md)

## Quick start

```bash
npm install
npm run dev
```

```bash
npm run test
npm run build
```

Optional Supabase: set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` (see [docs/PROJECT.md](./docs/PROJECT.md)).
